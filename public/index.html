01

Schema

A users table and a highly sensitive records table in managed Postgres, created by a versioned SQL migration.

02

Hash

Each new password gets a 128-bit CSPRNG salt. Only SHA-256(salt ‖ password) is stored; logins compare in constant time.

03

Encrypt

Title, subject and body are sealed with AES-256-GCM using a fresh IV per row, with the owner bound in as authenticated data.

04

Retrieve

After login the server queries only the owner’s rows, verifies each GCM tag, decrypts, and returns plaintext over HTTPS.
