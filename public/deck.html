06 · Step 3 — Encryption

AES-256-GCM, sealed before the INSERT.

const iv = randomBytes(12);          // fresh per row
const c  = createCipheriv("aes-256-gcm", aesKey, iv);
c.setAAD(`…:owner=${ownerId}`);      // bind to owner
const ct = c.update(json) + c.final();
const tag = c.getAuthTag();          // 128-bit MAC

await db.insert(records)
  .values({ ownerId, ciphertext, iv, authTag });

08 · Step 4 — Secure retrieval

Login → query → verify → decrypt → display.

  1. Authenticatesalted hash check, constant time
  2. SessionHMAC-signed · HttpOnly · SameSite=Strict · 30 min
  3. QueryWHERE owner_id = $1 (parameterised)
  4. VerifyGCM tag + owner AAD, refused if altered
  5. Decryptin server memory only, never cached (no-store)
  6. DisplayHTTPS → textContent (XSS-safe)
